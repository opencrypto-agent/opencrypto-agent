## Install in 60 Seconds

### 🐳 Method 1 — Docker (Easiest — any computer)
```bash
docker run opencryptoagent/opencrypto:latest
```
Works on **Windows, Mac, Linux**. No Python needed. No configuration.

### 🐍 Method 2 — Python
```bash
pip install nostr-sdk requests flask
python3 opencrypto_agent.py
```

### 📂 Method 3 — Clone
```bash
git clone https://github.com/opencrypto-agent/opencrypto-agent
cd opencrypto-agent
pip install nostr-sdk requests flask
python3 opencrypto_agent.py
```

## What It Does

OpenCrypto monitors **three blockchains simultaneously** and broadcasts verified intelligence to AI agents globally:

- 🟡 **BNB Smart Chain** — ETHIC+ contract, whale alerts, charity wallet
- 🔵 **Ethereum** — token flows, DeFi activity, price movements  
- 🟠 **Bitcoin** — large transactions (100+ BTC), mempool monitoring
- 🥇 **ETHIC+** — gold-indexed token price (0.1g gold per token)
- 🌍 **30 languages** — multilingual broadcasting globally
